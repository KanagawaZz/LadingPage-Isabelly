# Rascunho de contrato e avaliação da landing page

> **Uso recomendado:** este é um modelo inicial de negociação, não um parecer jurídico. Antes de usar com um cliente, preencha os campos, confirme o enquadramento fiscal da atividade e, se possível, peça a revisão de um advogado ou contador.

## 1. Avaliação do projeto atual

### O que foi identificado no código

O projeto atual é uma landing page estática em React + Vite, publicada por build na Vercel. Ele contém:

- layout responsivo para desktop e celular;
- cabeçalho com nome/foto e links para Instagram e WhatsApp;
- faixa de destaque com informações comerciais;
- seção inicial (hero) com chamada comercial e imagem principal;
- catálogo com três categorias: linha amarela, linha verde, caminhões e carretas;
- carrossel de imagens por categoria;
- seção de diferenciais do atendimento;
- seção institucional/apresentação da vendedora;
- seção de benefícios;
- seção “como funciona”;
- perguntas frequentes interativas;
- chamada final para contato;
- rodapé;
- botões flutuantes para WhatsApp e Instagram;
- animações de entrada, microinterações, parallax sutil e transição de blur no rodapé.

### O que não existe atualmente

Não fazem parte desta entrega, salvo contratação específica:

- painel administrativo;
- banco de dados;
- login ou cadastro de usuários;
- formulário que armazene leads;
- integração com CRM;
- venda ou pagamento online;
- analytics configurado;
- newsletter;
- área restrita;
- gerenciamento de conteúdo pelo cliente sem intervenção técnica.

### Estado atual que deve ser considerado

- A página possui uma foto de perfil e uma foto principal no projeto.
- As pastas de fotos das três categorias estão preparadas, mas podem permanecer sem imagens até o cliente fornecer o material.
- O código utiliza textos, marca e informações comerciais que devem ser confirmados pelo cliente antes da publicação definitiva.
- O número de WhatsApp e o link do Instagram são exibidos na página e devem ser fornecidos/autorizados pelo cliente.
- A página direciona o visitante para WhatsApp e Instagram; ela não armazena os dados que o visitante informa nessas plataformas.
- O projeto depende de serviços de terceiros, como Vercel, GitHub, WhatsApp, Instagram e carregamento de fontes externas. A disponibilidade e as regras desses serviços não são controladas pelo desenvolvedor.

### Referência de valor

Esta é uma referência comercial, não uma avaliação oficial de mercado:

- **Primeiro cliente / versão atual, com escopo controlado:** R$ 1.200 a R$ 1.800 pela criação.
- **Versão futura com conteúdo final, mais personalização e materiais organizados:** R$ 1.800 a R$ 3.000 pela criação.
- **Manutenção mensal:** R$ 150 a R$ 250, incluindo duas atualizações padrão de informação.
- **Hora adicional:** R$ 80 a R$ 150 por hora.

O valor final deve considerar prazo, quantidade de imagens, redação de textos, tratamento de fotos, criação de identidade visual, domínio, integrações e quantidade de revisões.
